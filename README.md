# NCPhO-Website

Hello, welcome to the official website for the North Carolina Physics Olympiad! NCPhO is an opportunity for experienced and inexperienced physics competitors to be introduced to physics. This competition was created in North Carolina by students at the North Carolina School of Science and Mathematics (NCSSM) but can be taken anywhere. Please register on the site to compete!

## Structure

- `index.html` — page markup for all sections (home, outreach, competition, practice, constants, team, archive)
- `styles.css` — all styling
- `script.js` — site config and data (`CONFIG` at the top), navigation, countdown, and the animated galaxy background
- `ncphoConstants.pdf` — the constants sheet embedded on the Constants page

## Updating content

Competition dates, links, team members, outreach events, and past results all live in the `CONFIG` object at the top of `script.js` — edit them there, no other changes needed.
